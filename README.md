# Automated Robotic Cart

![Automated Robotic Cart](Automated%20Robotic%20Cart/pic2.jpeg)

## Overview

The Automated Robotic Cart is a mobile robotic platform designed for material handling and pick-and-place operations. The system combines a robotic arm, gripper, and mobile cart to transport objects efficiently from one location to another.

The project integrates mobility and manipulation into a single system, making it suitable for industrial automation, warehouse logistics, educational robotics, and research applications.

---

## Features

- Mobile robotic cart
- Wireless control
- Pick-and-place operation
- Robotic arm with gripper
- Object transportation
- Embedded system based control
- Low-cost automation solution
- Educational and research platform

## Working Principle

1. The robotic cart receives control commands wirelessly.
2. BO motors drive the cart in the desired direction.
3. The robotic arm moves using servo motors.
4. The gripper picks up objects from a specified location.
5. The cart transports the object to the destination.
6. The arm places the object at the target position.
